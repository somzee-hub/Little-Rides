# Little Rides ERP for Odoo 19

Two modules:

- `littlerides_erp` (core, Community apps): channel-based stock (factory, Alipur, online), red/amber/green
  stock signal on quotations, Stock to Sell, Build Capacity, Component Cover with daily order-now to-dos,
  maker-checker on stock counts, scrap and manual vouchers, own-customers visibility, A/B/C price lists,
  advance payment terms, trucks on deliveries, ten users, and the Demo Data screen.
- `littlerides_erp_enterprise` (the app to install): Accounting, Follow-ups, Shop Floor, Quality,
  Helpdesk and Barcode on top of the core, with quality points and complaint tickets in the demo.

Install on a fresh 19.0 database without sample data. Install "Little Rides ERP"; the core comes with it.
Demo data: Little Rides > Configuration > Demo Data > Load / Remove.
Default password for the ten users: LittleRides@2026. Change before handing over.
